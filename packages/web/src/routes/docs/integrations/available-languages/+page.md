---
title: Language Plugins
---

English is built into Harper.
These languages are [language plugins](./language-plugins) that can be added to it.
Each one is made and released by its own project.

| Language | Id   | Project                                                               | Download                                                                                                      | Install                                         |
| -------- | ---- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| German   | `de` | [Dronakurl/harper-german](https://github.com/Dronakurl/harper-german) | [`harper-de.wasm`](https://github.com/Dronakurl/harper-german/releases/download/latest/harper-de.wasm) (always the newest build) | `just language-install Dronakurl/harper-german` |

To add a language to this list, publish its plugin as described under [Making a Plugin for a New Language](./language-plugins#Making-a-Plugin-for-a-New-Language) and open a pull request that adds a row here.
